# 分割CSVのダウンロード

MONOQLO PTランキングの対局記録(monoqlo-data の `YYYYMM.csv`)を10対局ずつに分けたCSVと、それを一覧からダウンロードするページを置くリポジトリ。
牌譜の成績を書き出す拡張機能の「対局一覧のCSVを読み込む」で、少しずつ・手分けして取得するために使う。

ページ: https://monoqlo-league.github.io/splitdata-download/

## ページの使い方

1. 取得したいファイルの行で、名前を入れる。名前は行ごとに入れる(ほかの行には入らない)。一度使った名前は、入力欄の候補に出る。
2. 「ダウンロード」を押す。名前・ファイル名・日時が記録され、CSVが保存される。
3. 記録は「取得した人」の列に出る。ほかの人が開いたページにも出る。

- すでに誰かが取得したファイルは、押すと確認が出る。もう一度押すと、自分の名前も記録して取得する。
- 同じ人が同じファイルを取り直しても、記録は増えない。
- 記録できなかったときは、ダウンロードもしない。少し待って押し直す。

## 中身

| ファイル | 役割 |
|---|---|
| `YYYYMM/YYYYMM-連番.csv` | 分割したCSV。1ファイル10対局(月の最後だけ端数)。開始時間の古い順 |
| `index.html` | 一覧とダウンロードのページ |
| `files.json` | ページが読むファイルの一覧。`tools/build-manifest.js` が作る |
| `config.js` | 記録先のURLを書くところ |
| `gas/Code.gs` | 記録先(Googleスプレッドシート)に貼るスクリプト |
| `downloads/majsoul-paifu-list.zip` | ページの「拡張機能をダウンロード(ZIP)」で配る拡張機能(雀魂 牌譜スタッツ出力 リスト取得版) |
| `downloads/majsoul-paifu-list-manual.pdf` | ページの「使い方マニュアル(PDF)」で開くマニュアル |

対象は 202511〜202608 の10か月、2,618対局、266ファイル。
202509・202510 は集計CSV(`-summary.csv`)が monoqlo-data にあるので入れていない。202609・202610 は対象外。

## 記録の仕組み

GitHub Pages は置いてあるファイルを見せるだけで、入力を保存できない。そのため、記録は Googleスプレッドシートに残す。
ページは、スプレッドシートに付けたスクリプト(ウェブアプリ)に名前とファイル名を送り、開くたびに記録を読み込んで表示する。

### 最初の設定(1回だけ)

1. Googleスプレッドシートを新しく作る。名前は何でもよい(例:「分割CSV DL記録」)。
2. メニューの **「拡張機能」→「Apps Script」** を開く。
3. 最初から入っているコードをすべて消し、このリポジトリの `gas/Code.gs` の中身を貼って、保存する。
4. 右上の **「デプロイ」→「新しいデプロイ」** を押す。
   - 「種類の選択」の歯車から **「ウェブアプリ」** を選ぶ。
   - 「次のユーザーとして実行」は **「自分」**。
   - 「アクセスできるユーザー」は **「全員」**。(「Googleアカウントを持つ全員」ではない)
   - 「デプロイ」を押す。初回はアクセスの承認を求められるので、自分のアカウントで許可する。
   - 承認の途中で「Google hasn’t verified this app(このアプリは Google で確認されていません)」と出る。自分で貼ったスクリプトには必ず出る表示。左下の「Advanced(詳細)」→「Go to …(unsafe)(…に移動)」→「Allow(許可)」と進む。
5. 表示された **「ウェブアプリのURL」**(`https://script.google.com/macros/s/…/exec`)をコピーする。
6. このリポジトリの `config.js` を開き、`endpoint: ""` の `""` の中にURLを貼って、コミットする。

1〜2分後にページを再読み込みすると、上の「記録先がまだ設定されていない」の表示が消える。
最初のダウンロードで、スプレッドシートに「DL記録」というシートができ、日時・ファイル・名前が1行ずつ入っていく。

### 記録を直す・消す

スプレッドシートの「DL記録」の行を、直接書き換えるか削除する。ページは次に読み込んだときに、その内容を表示する。

### スクリプトを直したとき

`gas/Code.gs` を貼り替えただけでは反映されない。**「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン」を「新バージョン」にして「デプロイ」** する。URLは変わらない。

## 拡張機能やマニュアルを新しくしたとき

`downloads/` の同じ名前のファイルを、新しいもので上書きしてコミットする。ページのボタンとリンクは、そのまま新しいファイルを指す。
拡張機能の版が変わったら、`index.html` の説明文にある版の番号(`v1.0.0`)も書き換える。

## CSVを足したり入れ替えたりしたとき

リポジトリの直下で次を実行し、できた `files.json` もCSVと一緒にコミットする。

```
node tools/build-manifest.js
```

## 注意

- 名前は自己申告。入力されたとおりに記録され、ページを開いた人全員に表示される。
- このリポジトリは公開なので、ページを通さずにGitHubから直接ファイルを取ることもできる。その場合は記録されない。
- 記録先のURLはページから見えるので、いたずらの書き込みは防げない。おかしな行は、スプレッドシートで消す。
