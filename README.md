# 分割した対局記録CSV

MONOQLO PTランキングの対局記録(monoqlo-data の `YYYYMM.csv`)を、10対局ずつに分けたCSVを置くリポジトリ。
牌譜の成績を書き出す拡張機能の「対局一覧のCSVを読み込む」で、少しずつ取得するために使う。

## 中身

- 月ごとのフォルダに、`YYYYMM-連番.csv` の名前で置いてある(例: `202608/202608-01.csv`)。
- 1ファイルは10対局。その月の最後のファイルだけ端数になる。
- 並びは開始時間の古い順。`-01` がその月の最初の10対局。
- 見出し行と各行の内容は、元の対局記録CSVと同じ。

合計 2,618対局、266ファイル。

## 入っていない月

- 202509・202510: 集計CSV(`-summary.csv`)が monoqlo-data にあるため。
- 202609・202610: 対象外。

## まとめてダウンロードする

このページ上部の **「Code」→「Download ZIP」** で、全ファイルを一度に取得できる。
