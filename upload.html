ゲームデータのアップロード

雀魂から書き出した対局記録と、拡張機能が出力した詳細成績(-summary.csv)を、個人戦・チーム戦どちらも、ここに入れるだけで置き場へ上げる。中身を読んで、行き先と名前を自動で決める。

1. GitHub でログイン

GitHub のログイン画面に移り、許可すると戻ってくる。上げられるのは、monoqlo-data と event-data に書き込める GitHub アカウントだけ。ログインは8時間ほどで切れるので、そのときはもう一度押す。コミットは、ログインした人の名前で残る。

2. 個人戦かチーム戦か

ログインすると選べる。選んだ種類のファイルとして上げる(中身で個人戦かチーム戦かを決めることはしない)。

3. ここにCSVを放り込む 何個でもまとめて入れられる。対局記録(牌譜履歴)と詳細成績(-summary.csv)を混ぜてもよい。

対局記録は、書き出したファイルをそのまま上げる(中身は変えない)。行き先は「2.」で選んだ種類で決まる。個人戦は対局の月、チーム戦はリーグ(置いてある対局記録と重なればそのリーグ、重ならなければ次のリーグ)。

詳細成績は、ゲームIDで対局記録と照らし、その対局が入っている月・リーグの summary に合体する。すでにある対局は重ねない。中身が違う同じ対局は、元の方を残して知らせる。

上げると、各リポジトリの自動処理(一覧の作り直し・点検・Discord への通知・分割CSVの追加)がいつもどおり動く。
